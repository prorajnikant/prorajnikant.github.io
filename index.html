About

I’m a security engineer at Postman, where I’ve worked since January 2022. My work sits where developer tooling meets security: making the safe way to ship code the easy way, hardening the software supply chain, and putting guardrails around AI coding agents before they become a problem.

Before Postman I was a security analyst at Mobitrail, testing applications for clients including ICICI Prudential Mutual Fund. I write about supply chain security on my blog and occasionally give talks on API and AI security.
