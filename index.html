About

I’m a security engineer at Postman, where I’ve worked since January 2022. My work sits where developer tooling meets security: making the safe way to ship code the easy way, hardening the path for secure product development, and building detection and prevention systems for modern software supply chains.

Before Postman, I was a security analyst at MobiTrail, where I was part of a 5-person team that secured the company’s CERT-In empanelment. I write about supply chain security on my blog and occasionally speak on API and AI security.
